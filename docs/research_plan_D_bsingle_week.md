# 研究计划 D（v2）：B 榜单周最大超额收益（2026-08-03 ~ 08-07）

日期: 2026-08-01（v2：纳入板块轮动维度，取消"无市场信息=负对照"的设定） |
提交截止: 2026-08-02 23:59 (北京时间)

## 0. 目标

B 榜只关心 8/3（周一）开盘买入 → 8/7（周五）开盘卖出这一周的组合收益
R = Σ wᵢ·rᵢ（信号日 2026-07-31）。目标：最大化 P(周超额 > 0) 与
E[周超额 | 当前状态]，并关注大胜周概率 P(超额 > 1%/2%)。

## 0.1 已完成的现状分析（D0）

[regime_analysis_2026.md](regime_analysis_2026.md) 的实证发现：

1. **7 月发生科技→老经济板块轮动**：信息技术 7 月累计 -7.3%（07-10 单周 -7.1%），
   而能源 +16.0%、主要消费 +11.7%、房地产 +10.6%、医药卫生 +9.8%、金融 +5.7%。
2. **Kronos Top-3 几乎每周 2-3 只都是信息技术**：5-6 月受益于科技领涨，
   7 月回吐（07-10 -1.9%、07-24 -4.5%）；模型把最近强势板块外推，
   训练数据（2024-25）中没有"科技见顶→消费/银行接力"样本。
3. **轮动速度加快**：5-6 月信息技术连续领涨（趋势态），7 月每周领涨板块
   均不重复（主要消费→能源→房地产），追上周冠军风险高（07-10 跟 IT 亏 -8.5%）。
4. **风格 IC 切换**：5 日动量 IC 5 月为正、6-7 月转负；20 日反转 IC 多数周为正，
   但裸反转 Top-3 无效（-1.4% 超额）——超跌股里有很多"接飞刀"。
5. **板块动量策略**（跟上周最强板块+板块内 Kronos 选股）窗口内超额 +1.29%、
   胜率 57%，略优于 Kronos Top-3（+1.07%），但轮动切换周大幅回撤。
6. **当前状态（07-31）**：广度 70% 站上 MA20（修复中）、波动升高、
   上周领涨=房地产/可选消费/主要消费，领跌=信息技术/通信服务 → B 周
   应倾向消费+金融+地产、回避科技；但轮动快，具体板块可能再变。

## 1. 核心假设（修订）

- **H1（状态条件化）**：市场状态 = 趋势 + 波动 + 广度 + **板块轮动阶段**
  （趋势态：单一板块连续领涨；轮动态：领涨板块快速切换；防御态：低估值/
  消费/红利占优）。不同状态对应不同最优策略。
- **H1b（科技-老经济相对趋势）**：信息技术相对主要消费/金融的 20 日相对强弱
  是短期超额的关键切换指标；科技失去领导地位后，应规避其内部高动量股票。
- **H2（短期信号增量）**：动量（5 日）、反转（20 日，需质量过滤）、
  板块动量（跟上周冠军，仅限趋势态）、板块内相对强弱、放量突破，
  在特定状态下对 5 日持有期有增量。
- **H3（状态仓位/风格倾斜）**：强趋势满仓 Top-3；轮动态降低追涨、倾斜到
  新领涨风格；防御态提高现金比例或选消费/金融/红利。
- **H4（融合优于单选）**：Kronos 分数 + 状态与板块条件的选择性融合优于单方。
- **H5（无市场信息可能是有效策略）**：B-C7（仅分数、无上下文）不再是负对照，
  而是候选策略——在上下文特征锚定旧板块（科技）的轮动态里，纯分数可能更稳。

## 2. 特征

### 市场/轮动状态（新增）
- 板块动量差：前 3 强势板块 vs 后 3 弱势板块的 5/20 日平均收益差
- 领涨板块持续性：最近 4 周领涨板块重复次数（趋势态=重复≥2，轮动态=≤1）
- 科技-老经济相对强弱：信息技术 20 日收益 - 主要消费/金融 20 日收益
- 风格 IC 区间：近 8 周 mom5 / rev20 IC 的均值与符号
- 广度/波动：>MA20 比例、20 日波动、分散度

### 个股短期信号（新增，秒级可算）
- 5 日动量、20 日反转（带过滤：收盘 > MA60 或 Kronos 分数为正）
- 距 52 周新高距离、放量比、布林带位置
- 行业内 5 日动量排名、行业 20 日动量方向

## 3. 实验设计（修订）

### Stage D1：状态定义（含轮动阶段）与状态-策略交互
- 用 2024-01 ~ 2026-07 全部周，按（趋势、波动、广度、轮动阶段）划 4-6 类状态。
- 对每个候选策略（Kronos-CS、B-C2/B-C4/B-C5、score-only/B-C7、板块动量、
  反转过滤、CardNN）统计每类状态的**条件周超额分布**（均值、胜率、上行捕捉、
  P(超额>1%/2%)、bootstrap 区间）。
- Gate D1：状态间策略排序差异显著 → 条件化成立；当前 07-31 状态落入哪类、
  该类最优策略是谁。

### Stage D2：信号单测（当前状态内）
- 逐信号在当前状态的条件下测超额；重点：板块动量（仅趋势态用）、
  反转+质量过滤、行业相对强弱、科技规避条件。
- Gate D2：至少 1-2 个信号在当前状态条件超额为正且与 Kronos 低相关。

### Stage D3：融合与配权
- 融合方式：Kronos 分数 × 板块状态倾斜（如对"科技失去领导地位"状态给 IT
  股票降权）+ 信号加权（α 候选 ≤5 个）。
- 配权：Top-3 等权 vs rank-weighted vs 状态仓位（现金比例）。
- 对照：仅分数（B-C7）、板块动量、反转过滤、各自单独。
- Gate D3：融合后条件周超额 > 各单方，bootstrap 中位数不劣于基线。

### Stage D4：07-31 单周决策包
- 判定 07-31 状态（当前：广度修复、轮动态、科技弱）→ 选状态内最优策略；
- 输出组合 + 决策依据（状态标签、信号读数、条件分布、bootstrap 区间）；
- 回退规则：状态样本 < 5 周或下界过差 → 回退满仓 Top-3（B-C2 或 Kronos-CS）；
- 产出 output/result.csv（≤5 只、权重和 ≤1），跑 test.sh 验证。

## 4. 统计严谨性
- 状态内样本小（5-15 周）→ bootstrap/置换检验报告分布，不用单点 Sharpe 决策。
- 对照策略全部并列报告（含"仅分数"），不再预设谁是负对照。
- 固定 seed 多运行取分位数；大胜周解剖（状态特征 → 当前是否相似）。
