# 研究计划 D：B 榜单周最大超额收益（2026-08-03 ~ 08-07）

日期: 2026-08-01 | 状态: 计划稿（待执行） | 提交截止: 2026-08-02 23:59 (北京时间)

## 0. 目标与成功标准

B 榜打分只关心 **8/3（周一）开盘买入 → 8/7（周五）开盘卖出** 这一个持有周的
组合收益 R = Σ wᵢ·rᵢ（信号日 2026-07-31）。本计划的目标不是"长期稳健收益"，
而是：

- 最大化 **P(周超额 > 0)** 与 **E[周超额 | 当前市场状态]**；
- 同时关注 **大胜周概率**（P(超额 > 1%)、P(超额 > 2%)），因为赛题按绝对收益排名，
  单周大涨周贡献最大；
- 最终产出：基于 2026-07-31 状态的**单周决策包**（组合、权重、历史条件分布、
  bootstrap 置信区间、回退方案）。

成功标准：所选策略在"与 07-31 最相似的历史状态"下的条件周超额均值 > 0，
胜率 > 50%，且 bootstrap 95% 区间下限不为大幅负值；组合满足 ≤5 只、权重和 ≤1。

## 1. 核心假设（全部待检验）

- **H1（状态条件化）**：市场状态（趋势/波动/广度/分散度）决定下一周哪种选股信号
  有效；当前状态（07-31）对应的最优策略与无条件最优不同。
- **H2（短期信号增量）**：动量（5 日）、反转（20 日超跌）、突破（52 周新高距离、
  放量、布林带）、行业内相对强弱对 5 日持有期有独立预测力，能提升 Top-3 命中。
- **H3（状态仓位）**：强趋势+低波动状态满仓 Top-3；震荡/高波动/下跌状态降仓或
  转现金/防御股，能提高单周超额概率与期望。
- **H4（融合优于单选）**：Kronos 分数 + 短期信号的条件加权融合，优于单独任一方。

## 3. 实验设计（分阶段，每阶段有 Gate）

### Stage D1：市场状态定义与状态-策略交互
- 用 2024-01 ~ 2026-07 全部周，按（趋势、波动）划 2×2=4 类状态
  （或 3 类：强趋势 / 震荡 / 下跌）。
- 对每个候选策略，统计每类状态下的条件周超额分布：均值、胜率、上行捕捉、
  P(超额>1%/2%)。
- Gate D1：状态间策略排序显著不同（如 B-C2 在上涨态最优、Kronos 在震荡态最优）
  → 状态条件化值得做；若所有状态排序一致 → 简化，用无条件最优。

### Stage D2：短期信号单测（当前状态内）
- 对每个短期信号单独构造 Top-3 组合，检验其在**当前状态**下的条件周超额。
- 计算信号与 Kronos 分数的周度 RankIC 相关性，选低相关且有条件的信号。
- Gate D2：至少 1-2 个信号在当前状态的条件超额为正，且与 Kronos 互补。

### Stage D3：融合与配权
- 融合：score_final = α·Kronos分数 + (1-α)·短期信号分（α 按状态或按验证周调，
  限制在 5 个候选 α 内，避免过拟合）。
- 配权对比：Top-3 等权 vs rank-weighted vs 状态仓位（现金比例按状态）。
- 负对照：信号打乱、时间倒置、状态标签打乱。
- Gate D3：融合后条件周超额 > 各自单独，且 bootstrap 中位数不劣于基线。

### Stage D4：单周决策包（07-31 信号日）
- 计算 2026-07-31 的市场状态与所有信号值；
- 用当前状态对应的最优策略输出组合与权重；
- 附决策依据：状态标签、信号读数、该状态下的历史条件分布（均值/胜率/大胜周概率）、
  bootstrap 区间；
- 回退规则：若当前状态的历史样本 < 5 周或 bootstrap 下界过差 → 回退满仓 Top-3
  （Kronos-CS 或 B-C2），避免空仓错过。
- 产出 output/result.csv（≤5 只、权重和 ≤1）并跑 test.sh 验证格式与耗时。

## 4. 统计严谨性

- 样本极小（状态内可能只有 5-15 周）：一律用 **bootstrap / 置换检验** 报告分布，
  不用单点 Sharpe 决策。
- 所有结论必须有负对照（shuffle/zero/倒置），负对照"最好"时按噪声处理。
- 固定 seed 多运行（3-5 个），报告分位数而非均值单点。
- 大胜周解剖：找出历史最大超额周的共同状态特征（如 06-26 周），检查当前状态
  是否相似——这是"最大化单周超额"的直接依据。

## 6. 明确不做的事

- 大规模超参网格（10 周样本极易拟合噪声，收益有限）。
- 重训 Kronos / 更换大模型（时间不足，且边际收益不确定）。
- 无条件多模型堆砌（只做有条件融合）。
- 以 21 周/10 周的无条件 Sharpe 作为 B 榜决策依据。

## 7. 与既有结论的衔接

- 10 周窗口显示：B-C2（市场头）跨窗口最稳，负对照噪声最高 → 决策必须条件化。
- CardNN 单 seed 累计最高但不稳 → 仅作为候选之一，不再默认。
- 最终推荐逻辑：**当前状态 → 状态内最优策略（含信号融合与仓位）→ bootstrap
  验证 → 回退规则兜底**。
