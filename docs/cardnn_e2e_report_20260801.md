# CardNN 端到端验证报告

日期: 2026-08-01 | 数据截止: 2026-07-31 | 评分来源: fine-tuned Kronos-small (lb60)

## 目的

在真实 Kronos 评分上验证端到端 CardNN 模型（Context Transformer 捕捉股票交互与市场
环境 + Gumbel-Sinkhorn Top-K 配权，直接以组合收益为损失），评估其相对生产基线
（Kronos-CS Top-3）、Context Transformer 精排头（B-C2/B-C4/B-C5）的增益，
并给出 B 榜（8/1-8/2）提交建议。

## 方法

- 评分缓存: temp/kronos_scores_cache_ft.pkl（训练 95 周 / 验证 4 周 / 测试 21 周，2026-02-06 ~ 07-31）
- 股票池: FridayFilter + ScreenProcessor（成交额前 70%、MA60、回撤 15%）筛选后横截面
- 训练: 阶段 1 NDCG warm-start 精排头（可选）；阶段 2 端到端组合收益损失
  （joint 或冻结精排头只训 CardNN），per-date-group，早停 patience，固定 seed
- 约束: 持仓 <= K 只（K=3/5），权重和 <= 1（虚拟现金资产）
- 评估: 确定性推理（无 Gumbel 噪声）；指标含 Sharpe/累计收益/胜率/RankIC/Hit@5 及配权诊断

## 关键结论

1. **纯端到端联合训练（e2e_k3_ret / e2e_k3_ndcg / e2e_k5_ndcg）不稳定。** 跨 3 个 seed
   的 Sharpe 均值接近 0（-0.5 ~ 1.4 大幅波动），负对照（shuffle/zero 上下文）反而更高
   （2.67 / 2.60），说明在 95 周训练样本上直接优化组合收益+可微选股会过拟合噪声。

2. **冻结精排头 + CardNN 配权（e2e_k3_ft）稳定但增益有限。** 3 seed Sharpe 1.16~1.84
   （均值 1.43），高于生产基线 Kronos-CS（1.16），但明显低于同一精排头在
   确定性 Top-3 配权下的表现（B-C5 Full Context 头 = 2.64），
   也低于 B-C4（2.86）。即：**学习式配权（CardNN）
   在真 Kronos 评分上未能超过简单 Top-3 等权配权**，学习到的现金/仓位调整不带来增益。

3. **比赛约束满足。** 所有配置持仓 <= K 只、权重和 <= 1（现金承接），输出可直接用于提交。

## B 榜建议

- **不建议在 B 榜直接部署 CardNN 配权层**：当前证据下它低于 B-C4/B-C5 精排头 + Top-3。
- 生产代码与配置已支持 CardNN（`exposure_mode: cardnn`），可随时切换验证；
  若继续推进，建议先改进训练（更大样本、更稳的 Top-K 松弛、多 seed 集成），再评估。
- 若追求当前窗口最优期望：优先 B-C4/B-C5 类 Context Transformer 头 + Top-3 配权。

## 局限

- 21 周测试窗口较短，含官方盲测周（仅评估）；端到端收益损失对 seed 与验证集选择敏感。
- Sinkhorn 松弛与确定性 Top-K 贪心推理存在近似偏差；Gumbel 噪声未退火。
- 训练样本 95 周偏少，配权层可学信号有限。
